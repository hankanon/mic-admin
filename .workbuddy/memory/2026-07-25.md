## 微前端后台管理系统设计文档
- 需求：设计微前端后台管理系统，monorepo 管理，Vue3 + Element Plus + 京东 micro-app；含主应用 main-app、子应用（文档发布 doc-app、权限管理 perm-app）、公共组件包 components（菜单/登录页/布局）、工具包 utils（请求/公共方法）；要求子应用脱离主应用可独立启动并自载菜单。
- 产出：`docs/micro-frontend-design.md`（13 章完整设计文档）+ 内联架构图。
- 核心技术决策：
  - pnpm workspace monorepo：apps/*（应用）+ packages/*（components/utils/config），公共包 `workspace:*` 源码直连。
  - 子应用双形态运行：`window.__MICRO_APP_ENVIRONMENT__` 判断；集成时只渲染 RouterView，独立时自套 BasicLayout + `getMenusByApp()` 过滤菜单；路由 base 用 `__MICRO_APP_BASE_ROUTE__` 或 `/`。
  - Vite 子应用需 micro-app iframe 沙箱；菜单唯一数据源 menuConfig，路径前缀由 AppMenu 统一剥离。
  - token：生产同域主应用下发，开发态各应用独立登录。
- 项目背景：mic-admin 工作区为空仓库，本次为从零设计，后续大概率进入实际搭建阶段。
